# Python-for-data-engineer

A beginner daily roadmap to learn data engineering from zero.

## 14-day starter plan

### Week 1: Foundations
- **Day 1**: Install Python, VS Code, and Git. Run your first Python script.
- **Day 2**: Learn Python basics (variables, data types, loops, functions).
- **Day 3**: Practice file handling in Python (read/write CSV and JSON).
- **Day 4**: Learn SQL basics (SELECT, WHERE, ORDER BY, GROUP BY).
- **Day 5**: Practice SQL joins and aggregations with sample datasets.
- **Day 6**: Learn data cleaning basics using pandas.
- **Day 7**: Build a mini script: load CSV -> clean data -> save output.

### Week 2: Data Engineering Basics
- **Day 8**: Learn what ETL/ELT means and map one simple pipeline.
- **Day 9**: Connect Python to a database (SQLite/PostgreSQL) and insert data.
- **Day 10**: Schedule a Python job (cron or task scheduler).
- **Day 11**: Learn basic data warehouse concepts (fact/dimension tables).
- **Day 12**: Try one cloud service overview (AWS/GCP/Azure data tools).
- **Day 13**: Learn version control flow (branch, commit, pull request).
- **Day 14**: Create a small end-to-end project and document what you learned.

## Daily routine (repeat)
1. Study for 45-60 minutes.
2. Practice by writing code for 30-60 minutes.
3. Write a short note: "What I learned today".
